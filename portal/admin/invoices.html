    Import from spreadsheet (CSV)

    Export your sheet as CSV from Excel / Google Sheets / Numbers (File → Download → CSV). Expected columns: Date, Description, Amount — plus optional Type (income/expense) and Category. If there's no Type column, negative amounts are treated as expenses. Dates can be YYYY-MM-DD or DD/MM/YYYY. Re-importing the same file won't create duplicates.
